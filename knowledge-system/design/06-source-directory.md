## Quarterly Source Review Checklist

Per the system methodology (04-system-methodology.md), every quarter:

1. For each source, assess signal density over last ~10 posts/episodes
2. Sources below 60% strong+weak signal density → probation
3. Sources on probation for 2 quarters → remove
4. Check perspective diversity: do we still have tech, business, academic, practitioner, AND contrarian voices per zone?
5. Check for new authoritative sources that have emerged (new labs, new researchers, new reports)
6. Verify all Tier 1 sources are still publishing / relevant
