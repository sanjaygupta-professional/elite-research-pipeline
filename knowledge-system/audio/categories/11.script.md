The lived lesson from my own agent work, the Amazon scraping pipeline and the Google Workspace plugin with ninety-two skills: start simple. One agent, well-scoped tools, MCP underneath. That pattern reaches production. Add complexity only when simple architecture demonstrably fails. Switching frameworks changes maybe twenty percent of your code; rewriting prompts changes eighty percent of the behavior. Observability is your debugger; without it, you fly blind on non-deterministic failures.
