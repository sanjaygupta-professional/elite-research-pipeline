## How to Use This System

### Phase 1: Build the Baseline
Fill every category file in `baseline/` to the standard defined in `baseline/README.md`.  
Validate against criteria in `design/03-success-criteria.md` before declaring baseline complete.

### Phase 2: Periodic Updates
Follow the cadence defined in `updates/README.md`.  
Each update adds to — never replaces — the baseline.

### Phase 3: POV Development
Use the accumulated baseline + updates to construct original futures scenarios  
in `baseline/zone2-futures-intelligence/03-long-arc-futures-pov.md`.

### Pipeline Integration
The automated pipeline (`assets/project-template/`) generates Intel Cards from new sources.  
Those Intel Cards feed the `updates/` layer, not the baseline.
