# Periodic Updates — How This Works

## What Updates Are

After the baseline is complete and validated, new knowledge enters the system as **dated updates** — not rewrites of the baseline. The baseline remains the foundation. Updates are the layer on top.

Updates live in `updates/YYYY/` as monthly log files.

---

## Update Format

Each monthly update file (`updates/YYYY/YYYY-MM.md`) follows this structure:

```markdown
# Intelligence Update — [Month Year]

## Strong Signals Added

### [Category Name]
- **[Date]** | [Signal — one sentence] | Source: [name/URL] | Implication: [one sentence]

## Weak Signals Added

### [Category Name]
- **[Date]** | [Signal — one sentence] | Source: [name/URL] | Why watching: [one sentence]

## Signals Upgraded (Weak → Strong)
- [Signal] — upgraded because [second source / corroboration]

## Signals Discarded
- [Signal] — discarded because [evidence against or lack of corroboration]

## Baseline Updates
*[If a baseline category file needed updating, note it here: which file, what changed, why]*

## Futures POV Changes
*[If the Long-Arc Futures POV was updated, note what position changed and why]*

## Experiments Completed (Zone 4)
*[Brief log of any local AI experiments or agent framework work done this month]*

## Tools Added or Removed (Zone 3)
*[Any new tools adopted or dropped from the practitioner toolkit]*
```

---

## Cadence by Zone

| Zone | Daily (10–15 min) | Weekly (30–45 min) | Monthly (2–3 hours) |
|------|------------------|--------------------|---------------------|
| **Zone 1: Present** | Skim strong signal sources | Classify + tag 3–5 new signals | Review: does any baseline section need updating? |
| **Zone 2: Futures** | Skim weak signal sources | Add to weak signal log; note clusters | Update futures POV if warranted |
| **Zone 3: Toolkit** | Use tools in normal work | Log notable tool insights (5 min) | Write one practitioner piece |
| **Zone 4: Lab** | — | Experiment or study session | Document experiment output |

---

## The Processing Rule

An item is not "processed" until it has been through all three steps:

1. **Classify** — Strong Signal / Weak Signal / Noise (discard Noise immediately)
2. **Extract** — Signal in one sentence + Implication in one sentence + Sanjay's reaction in one sentence
3. **Store** — Written into the monthly update file under the correct category

Bookmarking is not processing. Reading is not processing. Step 3 must happen.

---

## Annual Review

At the end of each year:
1. Review all 12 monthly update files
2. Identify the strongest themes that emerged
3. Update the baseline category files where the field has materially shifted
4. Update the Long-Arc Futures POV with dated notes on how positions evolved
5. Write a Year-in-Review: what was expected at the start of the year vs. what actually happened
